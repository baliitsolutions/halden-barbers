Halden — Barbershop Landing Page

Thank you for your purchase. This guide covers everything you need to put the template online with your own content. No build tools are required: open index.html in a browser and you're running. For a picture-by-picture walkthrough, see quick-start.pdf.

Change colours and fonts

Open assets/css/style.css and edit the variables in :root. The barber pole uses --red, white and --blue:

:root {
  --navy: #10203d;  /* text, headings, booking section */
  --red: #c8102e;   /* buttons and pole stripe */
  --blue: #1d3d8f;  /* pole stripe */
  --chalk: #eceee8; /* tinted section */
}

Services and prices

The price list and the booking options both come from SERVICES at the top of assets/js/main.js, so they always match:

{ group: "Cuts", name: "Skin fade", mins: 45, price: 40,
  desc: "Fade down to the skin, blended by hand." },

group is the heading on the price list, mins is how long the booking takes. Set CURRENCY at the top of the file.

Barbers

{ name: "Leo Hart", initials: "LH", role: "Owner · classic cuts & shaves",
  days: [2, 3, 4, 5, 6], photo: "assets/img/leo.jpg" },

days are the days they work (0 = Sunday … 6 = Saturday). The booking flow only offers times when that barber is in. Add photo to replace the initials; portrait photos around 800 × 1000 px work best.

Opening hours and booking rules

  • OPENING_HOURS: one line per day, 24-hour times, null for closed.
  • SLOT_STEP: minutes between start times (15 by default).
  • DAYS_AHEAD: how many days ahead people can book.

Connecting real bookings

The booking flow works on its own as a demo. DEMO_BUSY marks some times as taken so the calendar looks realistic; set it to false before you go live. The template has no database, so it can't know about bookings made by phone or by other visitors. Choose one of these:

  1. Receive requests by email (simplest). Create a free form at Formspree and paste its URL into FORM_ENDPOINT. Each confirmed booking is emailed to you with service, barber, time, name and phone. You then confirm by text.
  2. Use a booking app. If you already use Square Appointments, Booksy, Fresha or Calendly, replace the booking section with their embed code or change the "Book a chair" buttons to link to your booking page.

Publish

Upload the whole folder to any static host: Netlify, Vercel, GitHub Pages, Cloudflare Pages, or the public_html folder of regular web hosting.

Browser support

Current versions of Chrome, Edge, Firefox and Safari, on desktop and mobile. Keyboard accessible, and the moving barber pole stops for visitors who prefer reduced motion.
